# Anciennes versions du bot (non utilisées)

Gardées pour mémoire. Le seul bot actif est `deploy-bot/app.js`.

- `telegram-bot-old.mjs` — première version du bot Telegram
- `webhook-vercel-old.js` + `vercel-webhook-old.json` — version webhook pour Vercel

⚠️ Ne pas lancer une de ces versions en même temps que `deploy-bot/app.js` avec le même token :
Telegram n'accepte qu'un seul programme par bot.
